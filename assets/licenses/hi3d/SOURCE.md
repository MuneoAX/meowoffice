# Hi3D 생성 고양이 모델

- 생성: Hi3D (https://www.hitem3d.ai) 에서 고양이 기본 모델을 생성 → Blender 로 줄이기·뼈대·동작·품종별 변형 (`assets/cats/hi3d/*.py`)
- 앱이 쓰는 파일: `ui/office/models/cats/cat_*.glb`, `anims_*.glb`
- 조건(2026-11-25 확인, Hi3D FAQ): 무료 사용자도 상업 이용 가능, 단 제품 페이지나 상업 자료에 **"Generated with Hi3D"** 를 표기 — README·NOTICE.md 에 표기함
  - 출처: https://www.hitem3d.ai/ai-faq/how-hitem3d-ensures-compliant-and-copyright-safe-commercial-use
- 유료 요금제로 생성했다면 표기 의무가 다를 수 있다. 생성 당시 요금제를 확인해 이 파일을 고친다.
