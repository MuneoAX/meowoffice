# Google Gemini 이미지 생성 참조

- 품종 털 무늬 일부는 Google Gemini 이미지 생성 결과(`assets/cats/skins_in/gemini_*`, 저장소 밖 보관)를 참고해 만들었다.
- 조건(Gemini API 추가 약관 'Use of Generated Content'): Google 은 생성물의 소유권을 주장하지 않는다. 같거나 비슷한 결과가 다른 사람에게도 생성될 수 있고, 생성물 사용 책임은 사용자에게 있다.
  - 출처: https://ai.google.dev/gemini-api/terms
- 디자인 시안 이미지(`design/`)는 공개 저장소에 넣지 않는다(`scripts/export-public.mjs` 제외 목록).
